Questions, answered plainly.

If yours isn't here, ask on Discord.

Is Butler official?add

No. Butler is an unofficial client, not affiliated with JanitorAI. It uses your own Janitor account the way the website does, and nothing more.

Is it safe to install an APK from here?add

Every release is scanned on VirusTotal by the release workflow, carries its SHA-256, and is signed with the same key since the very first one. The code is open, and there's no Butler server that could collect anything. The Download page shows all of it, live.

How do I install it?add

Download the APK, open it, and allow your browser to install apps when Android asks. It installs over any earlier Butler and keeps your chats. Butler needs Android 8 or newer.

Will I lose my chats?add

No. Your chats live on your Janitor account, so Butler shows the same ones as the website and the official app. Uninstalling Butler only removes its copy on the phone.

Does it work with JLLM and proxies?add

Both. JLLM, Janitor's own model, and any reverse proxy you've saved on Janitor, like OpenRouter.

It said Janitor's firewall turned the request away. Is my account in trouble?add

No. That's Janitor's firewall, Cloudflare, not your account. Janitor tightens it now and then, and each time Butler gets a fix out fast. Update to the newest Butler; if it keeps happening, say so on Discord.

Why do I have to tap the Cloudflare box when I sign in?add

Cloudflare decides each visit whether to pass you silently or ask for a tap. Butler's sign-in starts with a fresh browser every time, so Cloudflare usually asks once. That's the check working, nothing more.

Does it cost anything?add

Butler is free and open source. Janitor's own limits apply as they do on the website, and a proxy costs whatever your proxy costs.

How do updates work?add

Download the newest APK and install it over the old one. Butler can also check GitHub for a newer version when you ask, or every time it opens if you turn that on. It never downloads anything by itself. An F-Droid listing has been submitted and is waiting on review.

Where do I report a bug or ask for a feature?add

On Discord or in GitHub issues. If a feature you asked for makes it in, you're credited in the README.

Is there an iPhone version?add

No. Butler is Android only.
